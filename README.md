# NLP-ChatBot

Supermarket Shelf Location NLP Chatbot

An NLP-based supermarket assistant that interprets natural-language shopping requests and identifies the shelf and aisle where requested products are located.

The system uses NLTK for tokenization, POS tagging, noun-phrase extraction and lemmatization, combined with fuzzy string matching to handle variations and misspellings in user input.

Example:

I want to buy some red apples and milk

→ identifies the requested products
→ searches the product database
→ returns their shelf and aisle locations.
